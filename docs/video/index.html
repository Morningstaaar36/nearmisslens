NearMissLens

Near-misses measured from drone video, ranked by hotspot, and matched to cited safety countermeasures.

-4.0 s

Mission control: the manager agent at work

Muse Wonder runs the review: it reads the audit, calls Muse Spark's video reviews, the review panel, the intake officer, the fix test and the persistence check, asks the city engineer to sign off, and writes a work order. Every claim passes the grounding checker; three refusals stop the run for a person.

How the review panel decided

Three agents argue the recommendations: a Proposer and a Skeptic (Muse Spark) and a Judge (Muse Wonder). A checker rejects any hotspot, CMF or number that is not in the audit, and the agent must correct it.

Complaints checked against the data

A spoken complaint is transcribed by Muse Voice Transcribe. Muse Spark extracts the road users, movement and approach, and a fixed rule looks for a hotspot whose conflicts show the same.

Who enters on red

Signal state when each road user entered the junction, by approach. From the tracks and the site's signal log.

Does it work?

Every row is recomputed from the data by nml selftest. Results on the pre-registered test and held-out clips appear below once evaluated.

What the city's own records say

For any US junction with open data, the context agent reads OpenStreetMap, the police-reported crash record and the city's safety plans (High Injury Network, Vision Zero priorities, street projects) and writes a memo in which every number is checked against the sources. FLUID's junctions are anonymised, so these are separate junctions in New York, Washington, Los Angeles and Chicago.

NML-Bench

Each agent measured against a baseline or an ablation, on all 14 FLUID flights and open city data. Generated by nml bench; pre-registered in validation/BENCH_PREREG.md.

Audit memo

Video, trajectories, signal logs and base maps: FLUID dataset (Scientific Data, 2026), CC BY 4.0. Crash modification factors: FHWA CMF Clearinghouse. Countermeasures: FHWA Proven Safety Countermeasures. Road users are anonymous per-clip tracks.

A screening tool built on surrogate safety measures. It does not predict crashes, and a qualified traffic engineer must review any design.
